# Avatars

Source : https://github.com/movixstream/MovixOpenSource/tree/9a7e784c520caaa8cb6b57d20b203ae9849d807c/public/avatars

1559 images PNG récupérées et vérifiées par leur empreinte Git. Les noms, personnages et illustrations appartiennent à leurs titulaires respectifs. Respecter la licence du dépôt et les droits associés aux médias.

La galerie utilise ces copies locales. Le profil Firebase conserve l’URL HTTPS de la version source pour rester portable entre les environnements ; l’interface la résout vers sa copie locale.

Actualisation explicite : node scripts/sync-avatars.cjs
