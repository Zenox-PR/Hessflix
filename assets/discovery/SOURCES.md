# Catalogue de découverte

Relevé : 2026-10-23. 51 titres.

Affiches de films : pages publiques de https://www.themoviedb.org et images TMDB associées, sans clé API. Le champ imageSource conserve la page source de chaque film.
Notes de films : jeu officiel IMDb https://datasets.imdbws.com/title.ratings.tsv.gz ; documentation https://developer.imdb.com/non-commercial-datasets/ .
Affiches et notes de séries : API publique https://www.tvmaze.com/api ; données TVMaze sous CC BY-SA. Chaque fiche renvoie à sa source.
Les résumés français courts sont rédigés pour cette interface. Les affiches et marques appartiennent à leurs titulaires.

Les Top 10 classent les meilleures notes de cette sélection, pas la popularité mondiale en temps réel. Les rangées Tendances et Sagas sont des sélections éditoriales. Aucun film, épisode ou flux vidéo n’est téléchargé.

Actualisation explicite : node scripts/sync-discovery.cjs
