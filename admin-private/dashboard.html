Configuration et aide

TMDB : renseignez votre clé v3 dans le fichier privé .env, après TMDB_API_KEY=, puis redémarrez le serveur. Ne collez aucune clé dans ce panneau ou dans un chat.

Firestore : dans Firebase Console, ouvrez le projet demo-hessflix, puis Firestore Database → Créer une base → édition Standard → mode Production. Choisissez la région avant de confirmer. Aucune activation n’est effectuée par ce panneau.

Les étapes complètes, les règles et les index sont documentés dans CATALOGUE_ADMIN.md, dans le dossier du projet.
